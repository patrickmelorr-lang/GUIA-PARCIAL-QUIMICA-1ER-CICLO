Plan de estudio para hoy

  1. Primero (60 min): Set 3 problemas 14–24 y 30–42 (estequiometría y gases; son los que más fácil se calculan mal).
  2. Segundo (45 min): Set 2 problemas 13–16 (Lewis y geometría) y 17–25 (fuerzas intermoleculares).
  3. Tercero (30 min): Set 2 problemas 1–12 (periodicidad y nomenclatura) con la tabla de nº de oxidación comunes.
  4. Cuarto (20 min): Set 1 completo en modo práctica.
  5. Antes de dormir (10 min): lee el formulario.
